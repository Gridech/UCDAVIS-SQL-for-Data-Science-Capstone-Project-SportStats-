# UCDAVIS-SQL-for-Data-Science-Capstone-Project-SportStats-

I have chosen ‘SportStats’ with the Olympics dataset, which contains over 120 years of data. I decided to use this dataset because I have some curiosity about these statistics, I want to uncover the deeper narrative behind Olympic success by moving beyond medal counts to analyze the impact of geography, demographics, and socioeconomics on global athletic achievement.
